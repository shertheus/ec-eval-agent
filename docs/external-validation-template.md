# 外部使用者验证记录模板

请由一位未参与开发的使用者完成安装和任务操作后填写。

| 项目 | 实际记录 |
|---|---|
| 使用者标识、是否参与开发 | 待填写 |
| 日期、操作系统、CPU/GPU | 待填写 |
| 项目提交号、镜像版本与 SHA-256 | 待填写 |
| 安装方式、起止时间 | 待填写 |
| 是否在 30 分钟内跑通 | 待填写 |
| 实际输入的任务 | 待填写 |
| 实验编号与运行结果 | 待填写 |
| 报告或证据 ZIP 的位置 | 待填写 |
| 遇到的问题、人工介入步骤 | 待填写 |
| 使用者反馈 | 待填写 |

建议完成一项生成数据的任务，再导入一份已授权数值矩阵，并使用数据检查和证据导出。保留命令、错误信息、最终状态和所用版本，便于复查。
